# Standard cryptographic constructions and global simplicity win

Status: accepted

Bittery first rejects any cryptographic design that misses its threat model. Among secure candidates,
complete final-RFC constructions with mature reviewed implementations win, followed by the smallest
global code, state, format, and migration surface. A bespoke or non-final-standard exception needs a
mandatory unmet property, written comparison, vectors, mature support, and independent review before
beta. Beta may otherwise precede integrated review, but design review, implementation review, and a
penetration test all block general availability.
