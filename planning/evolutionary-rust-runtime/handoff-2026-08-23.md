## Method to keep

The session's working rules produced most of its real findings. Keep them:

- One primary agent owns architecture, sequencing, and integration. Subagents get disjoint file paths.
- Implement test-first. Commit one slice at a time.
- After each slice, run two independent reviewerss over the fixed commit range, one for repository
  standards and one for the specification. Several genuine security races, secret-lifetime leaks, and
  data-loss paths in this branch were found only by that second pass.
- Conduct unresolved maintainer decisions in German. Write repository artifacts in English.
- Record a revised decision as a revision. The session reversed its own post-login decision and its
  own "discard pending Operations on re-login" recommendation, and wrote both down.
