## Contract

current authority. Preserve the direct visible-Item path with current crypto/category/version checks
and exact captured commit guards. Later versions or moves into another visible Vault are legitimate;
lower versions, corrupt present data and present permanent-delete contradictions remain rejected.

For unavailable visibility and every applied Import/Create-Vault result, reuse the existing original
receipt plus RefreshRequired under one guarded commit. Remove only owned work, preserve all current
authority and other Operations, abandon pre-proof staging and use the existing bounded Sync owner.

cursor or retrying forever. Crypto validation precedes fresh-data publication, not a receipt that
installs no data. Preserve exact original Import count and post-receipt artifact cleanup obligations.

ordinary/structural catch-up progression. Preserve failed-commit accepted bytes and artifacts.
