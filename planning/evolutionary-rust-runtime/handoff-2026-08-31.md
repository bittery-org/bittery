## Ticket 54 ownership decisions

Ticket 54 is the atomic E6 cutover. The reusable seam is fixed:

- Rust Runtime owns acceptance, generated IDs and keys, immutable request bytes, retry, outcomes,
  staging, cleanup, reconciliation, projections, and failure policy.
- `packages/client-runtime/src/client` owns the platform-neutral facade.
- Generic React subscription and create-Vault wrappers live under
  `packages/client-runtime/src/react`; they do not belong in `apps/web`.
- Web owns only browser `File`/`Blob` capability registration, query invalidation, routing, and
  presentation glue.
- A provisional browser image capability binds exactly once to the Operation and Vault identities
  generated by Rust. Invalid first claims, mismatched replay, expiry, cancellation, and retirement
  fail closed.
- Import target selection consumes the shared Runtime multi-Account writable-Vault catalog. It
  does not use transitional Core Vault-key storage as authority.
