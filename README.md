# Bittery

Bittery is being redesigned as a fully open-source, self-hosted, end-to-end encrypted password
manager for Web, browser extensions, Desktop, native iOS, and native Android.

The greenfield product is currently in specification and architecture discovery. Wayfinder maps,
specs, and tickets are version-controlled under [`planning/`](planning/) and are public like the
rest of this repository.

The frozen pre-greenfield implementation is available under [`legacy/`](legacy/FROZEN.md) as
read-only evidence. Greenfield code never imports, builds, or depends on it.
