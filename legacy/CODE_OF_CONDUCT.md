# Code of Conduct

## Our Standard

We want Bittery to be a respectful, practical, and security-minded project. Contributors are expected to communicate clearly, assume good intent, and keep discussions focused on the work.

Unacceptable behavior includes harassment, personal attacks, sustained disruption, publishing private information without consent, or any conduct that makes collaboration unsafe.

## Enforcement

Project maintainers may remove content, close discussions, or restrict participation for behavior that violates this code of conduct.

To report a concern, email `hello@bittery.com`. Security vulnerabilities should be reported to `security@bittery.com`.
