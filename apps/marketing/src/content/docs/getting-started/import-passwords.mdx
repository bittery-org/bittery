# Import Your Passwords

Switching to Bittery is painless. You can import passwords from most major password managers and browsers in just a few steps.

## Supported import sources

| Source | Format | Status |
|--------|--------|--------|
| **1Password** | CSV / 1PUX | Supported |
| **Bitwarden** | JSON / CSV | Supported |
| **LastPass** | CSV | Supported |
| **Dashlane** | CSV | Supported |
| **Chrome** | CSV | Supported |
| **Firefox** | CSV | Supported |
| **Safari / Keychain** | CSV | Supported |
| **KeePass** | KDBX / CSV | Supported |

## How to import

<Steps>
<Step title="Export from your current manager">
In your current password manager, find the **Export** option (usually in Settings). Export as **CSV** for the most reliable results.

<Callout type="warning">
The export file contains unencrypted passwords. Delete it immediately after importing into Bittery.
</Callout>
</Step>
<Step title="Open Bittery import">
In the Bittery web app or desktop app, go to **Settings → Import** and select your source.
</Step>
<Step title="Upload your file">
Select the exported file. Bittery will parse it and show you a preview of the items to import.
</Step>
<Step title="Review and confirm">
Review the detected items. You can choose which vault to import into and deselect any items you don't want.
</Step>
<Step title="Done">
All items are encrypted client-side and stored in your vault. The imported data never leaves your device unencrypted.
</Step>
</Steps>

## After importing

- Verify a few logins work correctly by visiting the websites
- Organize items into folders if desired
- Delete the exported CSV file from your computer
- Consider removing passwords from your old manager once you're confident
